# `info` 多行值的第 2 列对齐

> 2026-09-12 ｜ 提交 `fe6ad82`

**问题**：`info` 会把标签列补到最宽标签的视觉宽度，使首行值统一从「2 空格 + 标签列 + 1 空格」开始；但多行值的**续行**多缩进了一列（`"  {:width$} {}"` 在 `width+1` 之外又补了分隔空格），`notes` 中的空行还被打印成一片尾随空格。中英两套标签（CJK 双宽 vs `Installed size` 多词）都受影响。

**修复**（`src/cmd/info.rs`）：把渲染拆成 `layout()`（产出 `Vec<String>`）＋ `render()`（逐行打印，便于断言）；续行改为 `"  {:width$}{}"`，空续行直接输出真正的空行（对齐上游 `notes -join "`n"` 的空白分隔行）。

**验证**：`hok info -v git -L zh` 全部行值列 = 13、`-L en` = 17（首行与续行一致）；新增 2 个单测——混排中英标签下所有行（含续行）值列相同、空续行无尾随空格；`cargo test --workspace` 除 2 个环境性 `permission::*` 用例外全绿。
